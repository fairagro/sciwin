## `save`
The save command simply commits the changes made to a workflow using git. The workflow can be given by name or as a path to its `.cwl` file, e.g. `s4n save pipelines/demo.cwl`.

    ```txt frame="terminal" title="Usage"
    Saves a workflow

    Usage: s4n save [OPTIONS] <WORKFLOW>

    Arguments:
      <WORKFLOW>  Name of the workflow to be saved, or a path to its .cwl file

    Options:
      -q, --quiet  Only print errors
          --debug  Explain in high detail what the CLI is doing internally
      -y, --yes    Never prompt: confirm all questions and pick default choices
      -h, --help   Print help
    ```
