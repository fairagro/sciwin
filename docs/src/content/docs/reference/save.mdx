## `save`
The save command simply commits the changes made to a workflow using git.

    ```txt frame="terminal" title="Usage"
    Saves a workflow

    Usage: s4n save [OPTIONS] <WORKFLOW_NAME>

    Arguments:
      <WORKFLOW_NAME>  Name of the workflow to be saved

    Options:
      -q, --quiet  Only print errors
          --debug  Explain in high detail what the CLI is doing internally
      -h, --help   Print help
    ```
