## Shell completions
Shell completions are available using the `s4n completions` command

    ```txt frame="terminal" title="Usage"
    Generate shell completions

    Usage: s4n completions [OPTIONS] <SHELL>

    Arguments:
      <SHELL>  [possible values: bash, elvish, fish, powershell, zsh]

    Options:
      -q, --quiet  Only print errors
          --debug  Explain in high detail what the CLI is doing internally
      -h, --help   Print help
    ```
The command can be used to generate the shell completions for several shells.
```bash
s4n completions bash > completions.sh
```
