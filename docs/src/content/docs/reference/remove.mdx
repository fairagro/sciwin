## `remove`
The `remove` or `rm` command can be used to delete a CWL File while checking whether its linked in another one. 

    ```txt frame="terminal" title="Usage"
    Removes a CWL File from the workflows Directory

Usage: s4n remove <FILE>

Arguments:
  <FILE>  

Options:
  -q, --quiet  Only print errors
      --debug  Explain in high detail what the CLI is doing internally
  -y, --yes    Never prompt: confirm all questions and pick default choices
  -h, --help   Print help
    ```

If the tool is still used by a workflow, `remove` asks before deleting it. Pass `--yes` to skip the question. Without a terminal and without `--yes` the command fails instead of removing the tool.
