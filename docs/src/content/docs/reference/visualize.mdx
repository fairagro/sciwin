## `visualize`
Enables to publishing visual representation of workflows using either the GraphViz (dot) or mermaid format.

    ```txt frame="terminal" title="Usage"
    Visualizes a workflow

    Usage: s4n visualize [OPTIONS] <FILENAME>
    
    Arguments:
      <FILENAME>  Path to a workflow
    
    Options:
      -r, --renderer <RENDERER>  Select a flavor [default: mermaid] [possible values: mermaid, dot]
          --no-defaults          Do not print default values
      -q, --quiet                Only print errors
          --debug                Explain in high detail what the CLI is doing internally
      -h, --help                 Print help
    ```
