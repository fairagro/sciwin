To build SciWIn Client locally the repository needs to be cloned from GitHub:

## Cloning the repository
```
# Clone the repository
git clone https://github.com/fairagro/sciwin

# Navigate to the project directory
cd sciwin
```
Furthermore a [Rust](https://www.rust-lang.org/) environment needs to be set up.

## Setting up Rust
<Tabs>
  <TabItem label="Linux">
      Use the following Bash command to install Rustup
      ```bash
      curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
      ```
  </TabItem>
  <TabItem label="Windows">
      Use the Rustup installer from the [Rust website](https://www.rust-lang.org/tools/install).

      For WSL2 the following command can be used.
      ```bash
      curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
      ```
  </TabItem>
</Tabs>
If VSCode is used as development environment the [rust-analyzer](https://code.visualstudio.com/docs/languages/rust) extension needs to be installed.

## Build and test

SciWIn Client can then be built using the `cargo` commandline tool
```bash
cargo build
```

To build & run, `cargo run` can be used followed by `--` and the commands and parameters of SciWIn Client, e.g. `cargo run -- create python echo.py`.

For linting, clippy is used, matching what CI runs: `cargo clippy --all-targets --all-features --workspace`.

Unit and integration tests are run with [`cargo nextest`](https://nexte.st/) (matching CI): `cargo nextest run --workspace`. If logging to stdout needs to be displayed the no-capture flag can be set: `cargo nextest run --workspace --nocapture`.
