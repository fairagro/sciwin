## Get started
<p class="section-lede">Pick the side you'll work from - both open the exact same project.</p>

<div class="getstarted-split">
	<div class="gs-col">
		<div class="gs-head"><span class="gs-tag">Terminal</span><h3>SciWIn-Client</h3></div>
		<Steps>
		1. Install `s4n`. The easiest way is the installer script.
			<h4 class="flex items-center gap-2"><Icon name="linux" label="Linux"/> Linux</h4>
			```bash frame=none
			curl --proto '=https' --tlsv1.2 -LsSf https://fairagro.github.io/sciwin/get_s4n.sh | sh 
			```
			<h4 class="flex items-center gap-2"><Icon name="seti:windows" label="Windows"/> Windows</h4>
			```powershell frame=none
			powershell -ExecutionPolicy Bypass -c "irm https://fairagro.github.io/sciwin/get_s4n.ps1 | iex"
			```
		2. Initialize a project in your code repository.
			```bash frame=none
			s4n init
			```
		3. Record your first tool by prefixing any command with `create`.
			```bash frame=none
			s4n create python echo.py "Hello World"
			```
		</Steps>
	</div>
	<div class="gs-col studio-col">
		<div class="gs-head"><span class="gs-tag">Visual canvas</span><h3>SciWIn-Studio</h3></div>
		<Steps>
		1. Download the [latest release](https://github.com/fairagro/sciwin_studio/releases/latest) for your platform.
		2. Open a folder - a new one, or an existing `s4n` project.
		3. Drag a CWL file onto the canvas and connect it into a workflow.
		</Steps>
	</div>
</div>
